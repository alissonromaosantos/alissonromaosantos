Aplicação web desenvolvida para consulta e exploração de informações sobre Pokémon.

**Tecnologias:**

- React
- TypeScript
- Vite
- React Router
- GitHub Actions

**Funcionalidades:**

- Listagem de Pokémon
- Paginação
- Busca por nome
- Busca por habilidade
- Busca por tipo
- Deploy automatizado através de GitHub Actions

### 📇 Contacts API

API RESTful para gerenciamento de contatos, desenvolvida com foco em organização de código, separação de responsabilidades e aplicação de boas práticas de arquitetura.

**Tecnologias e conceitos:**

- Node.js
- Express
- TypeScript
- Zod
- PostgreSQL
- Redis
- Docker
- TDD
- Clean Architecture
- Domain-Driven Design
- BullMQ
- Integração com Stripe
- Integração com WhatsApp
- Envio de e-mails

O projeto está sendo desenvolvido de forma incremental, aplicando os conceitos estudados durante sua construção.
